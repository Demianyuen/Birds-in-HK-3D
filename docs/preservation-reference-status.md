# 保存性重建與官方資料參考

## 使用者已確認的方向

- 預設保存版，還原宏福苑初建成、入伙時的面貌與家的感覺。
- 官方資料參考層獨立切換；共用地理座標與碰撞。
- 第三人稱白鴿、多人開放世界、文字對話。
- 所有公開體驗排除火元素。

## 本機已實作

建築視覺層切換：`preservation` / `reference`。

目前保存版是 **CSDI 幾何上的美術預覽**，不是已完成的初建成重建。
美術染色與程序化窗格明確標示為藝術補足。
參考層恢復原材質顏色、粗糙度、金屬度和 shader hook，保留原貼圖。
切換不複製建築，不改變幾何、玩家位置、碰撞或多人房間。
新串流進來的建築沿用当前選取層。
Google Maps 對照使用參考材質，而非美術染色。

## 未解決的衝突及缺口

1. 初建成外牆配色、窗框、入口、庭園和設施需要同期影像或原圖則核對。
2. CSDI 取得日期不是建築拍攝日期，也不證明初建成面貌或當日現況。
3. 尚未從官方資料中逐一確認宏福苑各座的穩定 ID、邊界及還原範圍；不能把整片 Tai Po 染色當成宏福苑精修。
4. 現有地方規則要求 CSDI 為唯一建築来源；使用者新批准的保存性重建只在獨立、清楚標示的保存層擴展它。官方參考層仍不得加入假建築。
5. 初建成年份與戶型的先前聊天陳述不作新增模型的唯一依據；正式建模要保留可重查的原始來源與資料版本。
6. 現有底圖近看模糊；地圖道路紋理不是街道級實體幾何。
7. 多人服務目前是本機訪客會話；正式帳戶、公開 WSS 主機及負載容量尚待驗收。

## 驗收界線

材質切換測試與截圖只證明視覺層分離，不能證明歷史外觀還原完成。
初建成保存版需逐座參考比對；多人需跨瀏覽器與公開主機實測。
