# 保存性重建與官方資料參考

## 使用者已確認的方向

- 預設保存版，還原宏福苑初建成、入伙時的面貌與家的感覺。
- 官方資料參考層獨立切換；共用地理座標與碰撞。
- 第三人稱白鴿、多人開放世界、文字對話。
- 所有公開體驗排除火元素。

## 本機已實作

建築視覺層切換：`preservation` / `reference`。

目前保存版是 **CSDI 幾何上的美術預覽**，不是已完成的初建成重建。
美術染色與程序化窗格明確標示為藝術補足。
參考層恢復原材質顏色、粗糙度、金屬度和 shader hook，保留原貼圖。
切換不複製建築，不改變幾何、玩家位置、碰撞或多人房間。
新串流進來的建築沿用当前選取層。
Google Maps 對照使用參考材質，而非美術染色。

## 未解決的衝突及缺口

1. 初建成外牆配色、窗框、入口、庭園和設施需要同期影像或原圖則核對。
2. CSDI 取得日期不是建築拍攝日期，也不證明初建成面貌或當日現況。
3. 尚未從官方資料中逐一確認宏福苑各座的穩定 ID、邊界及還原範圍；不能把整片 Tai Po 染色當成宏福苑精修。
4. 現有地方規則要求 CSDI 為唯一建築来源；使用者新批准的保存性重建只在獨立、清楚標示的保存層擴展它。官方參考層仍不得加入假建築。
5. 初建成年份與戶型的先前聊天陳述不作新增模型的唯一依據；正式建模要保留可重查的原始來源與資料版本。
6. 現有底圖近看模糊；地圖道路紋理不是街道級實體幾何。
7. 多人服務目前是本機訪客會話；正式帳戶、公開 WSS 主機及負載容量尚待驗收。

## 房委會資料查證（本地日期 2026-09-06）

已讀取官方屋苑定位器所用的 HOS/2.json，找到宏福苑記錄 3085。
它的 `intakeYear` 為 1983，`blockNo` 為 8，`blockType` 為 Flexi 2，
並列出八座中英文名稱。詳見 `wang-fuk-source-manifest.json` 的來源與摘錄。

此處證明的是入伙年份，不能無條件等同於完工日期。
目前資料 `image` 為空、`furtherInfo` 為 `-`；先前對話聲稱已有
位置圖與各座平面圖，這次查證並未支持該說法，仍須尋找原始圖則。
官方屋苑標記不是各座測量座標，也不據此擅自移動遊戲原點。

已抽查區域 R9 圖塊及四個 R8 子內容，均未發現逐棟名稱或 batch 識別資料。
抽樣範圍、路徑和限制記於 `csdi-block-mapping-investigation.md`。
這不是對所有更細圖塊的結論；目前仍缺八座名稱與具體幾何的可信對應。

## 八座地址點（2026-09-06）

已透過政府地址查詢服務 `https://www.als.gov.hk/lookup`，逐一查詢
「宏福苑」加八座名稱，要求 JSON 回應。每次只接受中文屋苑名及樓宇名
同時精確匹配、且唯一的結果，不以搜尋分數最高者直接代替。
八次查詢均得到唯一精確匹配，並回傳 A–H 座及經緯度／東北坐標。
宏道閣搜尋分數為 64.29，其餘為 70；這些是搜尋匹配分數，不是測量精度。

資料保存於 `src/game/wangFukLocations.ts`，遊戲內的地址點示意圖由此生成。
已測試轉換至既有 east-up-south 遊戲座標；没有移動遊戲原點或替換建築。
示意圖北向上，明示「非建築輪廓或初建成圖則」；八座名稱、A–H 對應
及地址點可以作進一步空間核對，但仍不能證明樓宇邊界、高度或歷史外觀。

瀏覽器確認八個地址點可展開顯示，並重跑真實地圖雙人聊天及重連流程。
89 個測試與 build 通過。初建成建模及逐網格對應仍待完成。

## 驗收界線

材質切換測試與截圖只證明視覺層分離，不能證明歷史外觀還原完成。
初建成保存版需逐座參考比對；多人需跨瀏覽器與公開主機實測。
